# Changelog

## 1.0.0

Initial release.

- Import `.ics` calendar files via a command palette action.
- Automatically create one note per event with YAML frontmatter (title, start, end, location, status, organizer).
- Attendees listed as checkboxes for easy tracking.
- Event description included in the note body.
- Overwrites existing notes with the same title on re-import.
